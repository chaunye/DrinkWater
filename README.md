# DrinkWater

> 你今天喝水了吗？ — 一个假装提醒你喝水，实际上管你一切的 Android 应用

## 这是什么？

表面上，它叫 DrinkWater，提醒你喝水。

实际上，它是一个**私人管家**。你打开抖音的时候它会问你「作业写完了吗」，你打开游戏的时候它会问你「单词背了吗」，你打开微博的时候它会问你「今天喝水了吗」。

**你设什么它就问什么，全看你良心有多痛。**

一名大一学生的个人项目。初衷是自己手机瘾太重，想做一个工具来监督自己。代码写得青涩，但功能实打实地能用。欢迎各位大佬提 Issue、提 PR！

## 功能特性

- **打开应用就弹窗** — 盯上抖音、微信、游戏，一打开就弹出你的待办提醒
- **待办清单** — 首页就是你的待办列表，添加事项后自动关联弹窗提醒
- **全局应用** — 一键把待办同步到所有监控的应用，不用一个个配
- **自定义弹窗图片** — 可以设置弹窗图片和背景图，提醒也要有仪式感
- **全屏 / 浮窗** — 两种弹窗模式，浮窗模式能盖在其他应用上面
- **延迟提醒** — 手滑点错了？延迟一下，过会儿再提醒你
- **生词本** — 导入词表，打开应用时顺便背个单词
- **时段控制** — 可以设置只在特定时段提醒，睡觉时间不打扰
- **完全离线** — 不联网，不收集数据，你的秘密只有你自己知道

## 隐私

**完全离线，不联网，不收集任何数据。** 你的待办、你的词表、你的良心拷问记录，全部存在你自己手机上。

## 技术栈

- Kotlin + Jetpack Compose
- Room 本地数据库
- AccessibilityService 应用检测
- WorkManager 定时任务
- DataStore 偏好设置
- Apache POI (Excel 读取)

## 权限说明

| 权限 | 用途 | 为什么需要 |
|------|------|-----------|
| 无障碍服务 | 检测你打开了哪个应用 | 不然怎么知道你又在刷抖音 |
| 通知权限 | 定时提醒 | 到点了该喝水了 |
| 悬浮窗权限 | 弹窗盖在应用上面 | 确保你逃不掉 |
| 文件读取 | 导入词表 | 背单词用的 |
